# Hiperfoco — V1 de lanzamiento

Sitio estático sin dependencias, preparado para GitHub y Netlify.

## Publicar
1. Sube el contenido de esta carpeta a la raíz del repositorio.
2. En Netlify, conecta el repositorio.
3. Build command: déjalo vacío.
4. Publish directory: `.`

## Antes del lanzamiento
- Completar datos legales.
- Conectar enlaces de afiliación reales.
- Configurar dominio y DNS.
- Añadir analítica y consentimiento si usa cookies no necesarias.
- Validar cada nota y afirmación editorial.

## Añadir nuevas reviews
Las páginas se generan con la estructura editorial definida. Para mantener consistencia, conviene actualizar el generador o pedir una nueva versión del repositorio.
